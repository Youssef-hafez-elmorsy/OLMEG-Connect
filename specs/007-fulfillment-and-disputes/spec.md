# Spec: Fulfillment and Disputes

**Status**: Planned  
**Entry gate**: Paymob payment/order state must be stable.

## Goal

Add a real order lifecycle from paid order through seller fulfillment, delivery, refund requests, and disputes.

## Scope

- Order lifecycle states.
- Seller accept/reject workflow.
- Tracking code and delivery update workflow.
- Buyer delivery timeline.
- Refund request and damaged-product report workflow.
- Admin mediation tools.

## Exit Gate

- Buyer, seller, and admin see consistent order lifecycle state.
- Dispute actions are backend-validated and audited.
